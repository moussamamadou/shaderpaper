ShaderPaper — system catalogue

Twenty-three generative systems, each shown as four variations — the same shape as one collection in the 5 × 4 plan. Organised by your taxonomy, with the art-directed tier first because it is the one that answers the artistic-appeal problem.

Everything renders live and locally. Nothing is published. Sections render on first visit, so switching tabs the first time takes a moment.

Consolidated from the earlier systems.html, taxonomy.html and composition.html, which this file replaces. Written analysis lives in ../docs/roast-verdict.md.

Hard-edge work is drawn with Canvas2D rather than shaders on purpose — vector paths stay crisp at any output size. For print you would export those as SVG or PDF, not PNG.
