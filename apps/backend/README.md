# ShaderPaper backend

Medusa 2.17.2, copied from MapAndSky (Méridien)'s `apps/backend` and adapted to shader posters. The full write-up (what was copied, what changed, placeholders, how to run it) is [docs/storefront/backend.md](../../docs/storefront/backend.md).

```bash
cp .env.template .env        # fill DATABASE_URL, JWT_SECRET, COOKIE_SECRET
pnpm install                 # from the repository root
npx medusa db:migrate        # migrations, then the seed (src/migration-scripts/initial-data-seed.ts), once
npx medusa user -e <email> -p <password>   # an admin
pnpm dev                     # http://localhost:9000, admin at /app
```

| Piece | File | What it does |
| --- | --- | --- |
| Poster list | `src/poster/posters.json` | Generated by `scripts/extract-posters.mjs` from `explorations/index.html` and the gallery's data; do not edit by hand |
| Catalogue | `src/poster/catalog.ts` | Sizes, frames, prices (Méridien's, placeholders), collections, Prodigi SKUs (null, business input), product input |
| Seed | `src/migration-scripts/initial-data-seed.ts` | Store, region, tax, stock location, shipping, 6 collections, 54 products; idempotent (`pnpm seed` runs it again) |
| Print files | `src/poster/print-files.ts`, `src/workflows/render-poster-print-files.ts` | Renders each shader poster line with `apps/print-renderer`, stores a private PNG, records `metadata.poster.print_file` (or `print_error`) |
| Trigger | `src/subscribers/poster-order-placed.ts` | Runs the print-file workflow on `order.placed` (never Prodigi) |
| Prodigi | `src/poster/prodigi.ts`, `src/poster/prodigi-submit.ts` | Print API v4 client (orders, quotes, products); off without `PRODIGI_API_KEY`, sandbox by default |
| Admin API | `src/api/admin/orders/[id]/poster-print-files`, `src/api/admin/orders/[id]/prodigi`, `src/api/admin/prodigi/status` | Print files (GET, POST render), send to Prodigi (POST, manual), Prodigi status (GET) |
| Admin UI | `src/admin/widgets/poster-print-files.tsx` | Order page panel: download, render, send to Prodigi |

| Script | |
| --- | --- |
| `pnpm dev` | `medusa develop` |
| `pnpm seed` | The seed again (idempotent) |
| `pnpm test:unit` | Jest unit tests (`src/**/__tests__/*.unit.spec.ts`) |
| `pnpm typecheck` | Server code, then the admin extensions |
| `pnpm lint` | `medusa lint` |
| `pnpm extract-posters --gallery <dir>` | Regenerates `src/poster/posters.json` (Playwright + Chromium) |
