## Custom map posters

The storefront's poster builder (`apps/storefront/app/poster`) sells posters through two products, and this backend renders their print files.

| Piece | File | What it does |
| --- | --- | --- |
| Catalogue | `src/poster/catalog.ts` | Sizes (with print resolution), frames, starting prices |
| Products | `src/migration-scripts/map-poster-products.ts` | Creates `map-poster` (12 size × frame variants) and `map-poster-digital` on `medusa db:migrate`, once |
| Print files | `src/workflows/render-poster-print-files.ts` | Renders each poster line with `apps/print-renderer`, stores a private PNG with the File Module, records it in `metadata.poster.print_file` (or `print_error`) |
| Trigger | `src/subscribers/poster-order-placed.ts` | Runs the workflow on `order.placed` |
| Admin API | `src/api/admin/orders/[id]/poster-print-files/route.ts` | `GET`: the order's posters with download URLs. `POST { force? }`: render missing files (all with `force`) |
| Admin UI | `src/admin/widgets/poster-print-files.tsx` | Order page panel: download, render, render again |

Set `PRINT_RENDERER_URL` and `PRINT_RENDERER_TOKEN` (see `.env.template`). Without them, poster lines get a `print_error` that the admin can clear with "Render" once configured.

## What is Medusa

Medusa is a set of commerce modules and tools that allow you to build rich, reliable, and performant commerce applications without reinventing core commerce logic. The modules can be customized and used to build advanced ecommerce stores, marketplaces, or any product that needs foundational commerce primitives. All modules are open-source and freely available on npm.

Learn more about [Medusa’s architecture](https://docs.medusajs.com/learn/introduction/architecture) and [commerce modules](https://docs.medusajs.com/learn/fundamentals/modules/commerce-modules) in the Docs.
